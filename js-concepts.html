JavaScript Concepts

Interactive demonstrations of Array Methods, Callbacks, and Functional Programming

1️⃣ Array Methods (Map, Filter, Reduce)

MAP: Transform each element in an array and return a new array

// Double each number const numbers = [1, 2, 3, 4, 5]; const doubled = numbers.map(num => num * 2); // Result: [2, 4, 6, 8, 10]

FILTER: Keep only elements that pass a condition

// Keep only even numbers const numbers = [1, 2, 3, 4, 5, 6]; const evens = numbers.filter(num => num % 2 === 0); // Result: [2, 4, 6]

REDUCE: Combine all elements into a single value

// Sum all numbers const numbers = [1, 2, 3, 4, 5]; const sum = numbers.reduce((total, num) => total + num, 0); // Result: 15

2️⃣ Callback Functions

CALLBACK: A function passed to another function, executed later

// Simple callback function greet(name, callback) { callback(`Hello, ${name}!`); } greet('Fiastara', (message) => console.log(message)); // Output: Hello, Fiastara!

3️⃣ Functional Programming Concepts

PURE FUNCTIONS: Same input always produces same output, no side effects

// Pure function - always returns same result function add(a, b) { return a + b; } console.log(add(5, 3)); // Always 8

FUNCTION COMPOSITION: Combine multiple functions

const pipe = (...fns) => (x) => fns.reduce((v, f) => f(v), x); const add10 = (x) => x + 10; const double = (x) => x * 2; const process = pipe(add10, double); console.log(process(5)); // (5 + 10) * 2 = 30
Input: 5 ↓ Add 10 → 15 ↓ Multiply by 2 → 30 ↓ Output: 30

CURRYING: Break function into chain of single-argument functions

// Regular function function multiply(a, b, c) { return a * b * c; } // Curried version const curry = (a) => (b) => (c) => a * b * c; const byTwo = curry(2); const byTwoByThree = byTwo(3); console.log(byTwoByThree(4)); // 2 * 3 * 4 = 24

⚙️ Advanced Concepts

ARROW FUNCTIONS: Concise syntax for writing functions with implicit return

// Regular function function add(a, b) { return a + b; } // Arrow function equivalent const addArrow = (a, b) => a + b; // With destructuring const users = [{name: 'John', age: 30}, {name: 'Jane', age: 28}]; const names = users.map(({name}) => name);

SPREAD OPERATOR: Expand elements in arrays/objects

// Array spread const arr1 = [1, 2, 3]; const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5] // Object spread const obj1 = {a: 1, b: 2}; const obj2 = {...obj1, c: 3}; // {a: 1, b: 2, c: 3} // Clone and modify const updated = {...obj1, b: 10}; // {a: 1, b: 10}

TEMPLATE LITERALS: Create strings with embedded expressions

// Without template literals const greeting = "Hello, " + name + "!"; // With template literals (backticks) const greetingNew = `Hello, ${name}!`; // Multiline strings const bio = ` Name: ${user.name} Email: ${user.email} Role: ${user.role} `;

DEFAULT PARAMETERS: Set default values for function arguments

// Without defaults function greet(name, age, role) { console.log(`${name} is ${age} years old and works as ${role}`); } // With defaults function greetDefault(name = 'Anonymous', age = 18, role = 'User') { console.log(`${name} is ${age} years old and works as ${role}`); } greetDefault(); // Uses all defaults greetDefault('John'); // Uses provided + defaults

🎓 Recommended Learning Path

  1. Start with Array Methods: Learn map, filter, reduce basics
  2. Understand Callbacks: How functions are passed and executed
  3. Arrow Functions: Modern syntax for writing functions
  4. Functional Programming: Pure functions and composition
  5. Advanced Patterns: Currying, memoization, higher-order functions
  6. Build Projects: Apply concepts to real-world scenarios

🎯 Real-World Example: Processing Student Data

Filter students with high average, sort by grade, and format names

const students = [ { name: 'Fiastara', scores: [85, 90, 88] }, { name: 'John', scores: [78, 82, 80] }, { name: 'Jane', scores: [92, 95, 89] } ]; // Calculate average const avg = (scores) => scores.reduce((s, v) => s + v, 0) / scores.length; // Process data const topStudents = students .map(s => ({ ...s, average: avg(s.scores) })) .filter(s => s.average >= 85) .sort((a, b) => b.average - a.average) .map(s => `${s.name} (${s.average.toFixed(1)})`);
