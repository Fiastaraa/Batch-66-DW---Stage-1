🎨 UI/UX Design

Creating intuitive interfaces with emphasis on usability and aesthetics

Project Overview

As a UI/UX designer, I've created numerous intuitive user interfaces using Figma, emphasizing usability and aesthetics. During my internship at Humanity First International, I designed web interfaces and navigation systems for their digital platform. I focus on understanding user needs and creating solutions that are both beautiful and functional.

Design Philosophy

My design approach is guided by:

🎯 User Centricity: Every design decision is based on user research and feedback
✨ Simplicity: Clean, minimal designs that reduce cognitive load
🔄 Consistency: Unified design language across all interfaces
♿ Accessibility: Designed for all users, including those with disabilities
📱 Responsiveness: Works seamlessly across all devices and screen sizes
