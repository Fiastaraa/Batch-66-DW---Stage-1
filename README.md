# Fiastara Express + Handlebars Demo

This project is a single-folder example app that combines:

- HTML, CSS, Bootstrap, and Flexbox
- JavaScript data types, variables, functions, loops, arrays, objects, operators, conditionals, dynamic rendering, form handling, higher-order functions, async/await, and localStorage
- Express.js routing and dynamic routing
- Handlebars template engine, helpers, expressions, and reusable partials
- CRUD for project data using JSON files

## Run it

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Main routes

- `/` home page with JavaScript demos and async API rendering
- `/projects` project list
- `/projects/new` create form
- `/projects/:slug` project detail
- `/projects/:slug/edit` update form
- `/contact` contact page with localStorage draft handling
- `/api/projects` JSON API
